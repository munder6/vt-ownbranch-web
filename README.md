# Vibe Test evidence

Screenshots captured by [Vibe Test](https://vibe-test.tech) during automated
QA runs, stored here so they can render inline in the issue comments that
reference them.

This branch (`vibe-test-evidence`) is an ORPHAN branch: it shares no history with your
code, carries no workflows, and never touches your default branch. Nothing
here is used by your application — deleting the branch only breaks the images
in past issue comments.

Layout: `issue-<number>/run-<run-id>/<screenshot>`
